You design the thumbnail for a "$brand_name" video ($niche).

Goal: a high-click-through-rate YouTube thumbnail that TELLS A STORY in one picture: one dominant subject,
an exaggerated emotional expression, dramatic lighting, high contrast, a clean background, and 2 to 4 bold
readable words that match the picture. Visually striking, curiosity-driven, uncluttered, optimized for
mobile viewing. Avoid generic AI-looking designs, excessive elements, and unnecessary details.

Video title: $title
Core fact of the video (the truth; the thumbnail must agree with it):
$core_fact
Video narration:
$narration

Text chosen by the user (if any): $user_text
If the user chose a text, use it EXACTLY as the text and as the first text option,
and design the symbol and the image so they show what that text says.

Think in this order:
1. symbol: ONE concrete object or visual metaphor that shows the CORE FACT in one glance
   (not a side detail, not a myth). Examples: too many decisions -> a crossroads with many arrows,
   or a pile of choices; being watched -> a giant spotlight; memory -> a cracked photo frame.
2. image_prompt: MAIN_CHARACTER interacting with the symbol, so the picture tells the story.
   Use the token MAIN_CHARACTER exactly (do not describe the character's look). Max 45 words. It must have:
   - MAIN_CHARACTER as the dominant subject, close-up or medium close-up, filling most of the frame
   - one exaggerated emotional expression that fits the story (shocked, confused, terrified, mind blown)
   - the symbol as a SEPARATE object next to the character or in its hands. The character always keeps
     its own head, face and body; the symbol never replaces or merges with any part of the character
   - dramatic lighting: strong light from one side, deep shadows, bright rim light
   - high contrast against a clean background with one bold color
   - empty space in the upper third for the text
   - never text, letters, numbers, real people, celebrities or brands in the image
3. text_options: 5 different texts. Each follows the text rules below. Put the best one first.
4. text: the best of the text options.
Text rules: 2 to 4 bold words, ALL CAPS, that describe what the picture shows and create curiosity.
   The text and the image tell the SAME story. The text must be TRUE according to the core fact and the
   narration: never state a myth, a debunked idea or a debated claim. No hashtags, no emojis.
   Do not repeat the title.
